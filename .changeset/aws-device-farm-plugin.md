AWS Device Farm moves to the `@agent-device/aws-device-farm` plugin, which publishes on the `nightly-0.22` tag. Install it with `agent-device plugins add @agent-device/aws-device-farm@nightly-0.22`, or with the exact version a missing-plugin error names for the release you run; the bare package name resolves to a placeholder and fails with `incompatible_plugin`. Finish sessions, stop the detached daemon for its matching state directory, and retry. Embedded hosts import the factory, pass it to `startAgentDevice({ plugins: [awsDeviceFarm()] })`, and close and recreate the runtime after changes.
