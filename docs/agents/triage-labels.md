# Issue Label Workflow

Each of these five triage roles has a GitHub label with the same name.

| Label | Apply when |
| --- | --- |
| `needs-triage` | Apply to every new issue. Once the issue is understood and valid, remove it. |
| `needs-info` | Reporter or external input is required. |
| `ready-for-agent` | Fully specified. An AFK agent can start without extra human context. |
| `ready-for-human` | Only the Chief of Staff agent applies it. |
| `wontfix` | Only after an explicit maintainer decision not to act. |

Even if a skill's triage step names `ready-for-human`, no other agent adds or removes it on an issue or PR.
